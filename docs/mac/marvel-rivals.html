Marvel Rivals on Mac

Mac players report it runs

A Mac player reported it running through Highball (4/5) (M4 Pro 2026-10-21); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Reported playable on the default engine with D3DMetal over 7 minutes, smooth by the reporter's account, with frame drops they tie to framing and the connection. The game asks about the graphics driver at launch and runs after it, and it drains the battery fast, so the reporter suggests playing plugged in. The anti-cheat map lists NetEase Game Security for it. Nothing was measured here.

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
