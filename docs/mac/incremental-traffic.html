Incremental Traffic on Mac

Mac players report it runs

A Mac player reported it running through Highball (5/5) (M4 Pro 2026-11-06); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Reported perfect on an M4 Pro with DXMT on the default engine (r28) over 59 minutes, and on an M3 with slight stutters while loading maps and one crash loading a save (highball-db#1102). An M3 Pro played it nearly seven hours and rated it playable with minor issues, none named (highball-db#1100).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
