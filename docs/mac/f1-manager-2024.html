F1 Manager 2024 on Mac

Mac players report it runs

A Mac player reported it running through Highball (M1 2026-10-01); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Installed through Highball's Epic support with the Visual C++ runtimes, then crashed at the copyright screen, where the game starts its intro video, without writing a log of its own. Just before the crash the graphics layer printed 'Invalid device handle' for a shared texture, the failure engines before r13 had when a game and its video player share a texture. How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
