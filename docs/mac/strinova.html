Strinova on Mac

Mac players report problems

A Mac player reported problems through Highball (2/5) (M1 2026-10-30). Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Registering and signing in work, but pressing Start in the game's launcher ends Strinova.exe on an illegal instruction. The game runs on Linux, so the likely cause is an instruction Rosetta doesn't implement, not the anti-cheat refusing Wine. Not confirmed yet.

Linux (Proton) reference: 118 of 176 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
