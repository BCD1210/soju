XCOM: Enemy Unknown on Mac

Mac players report it runs

A Mac player reported it running through Highball (4/5) (M4 Max 2026-11-08); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Playable on an M4 Max over 108 minutes once set up: a 16:9 resolution such as 2560x1440 rather than ultrawide, and Keep game files inside this environment (the environment's Compatibility settings) so the game's config doesn't live in the Mac's Documents folder.

Linux (Proton) reference: 26 of 29 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
