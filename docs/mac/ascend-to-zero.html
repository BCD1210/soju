Ascend to ZERO on Mac

Mac players report it runs

A Mac player reported it running through Highball (4/5) (M2 Pro 2026-10-09); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Reported playable on DXMT, the default mode, with frame drops and a little stutter. The session was one minute, so this covers the start only.

Linux (Proton) reference: 7 of 8 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
