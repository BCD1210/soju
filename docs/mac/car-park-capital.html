Car Park Capital on Mac

Mac players report it runs

A Mac player reported it running through Highball (5/5) (M4 Pro 2026-10-15); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Does not run. The game opens a console window that closes within seconds. Players on CrossOver see 'GLFW ERROR: WGL: Failed to create OpenGL context': the game needs OpenGL 4.2 and macOS stops at 4.1, so no Mac OpenGL driver can give it the context it asks for. How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
