Frozen Synapse on Mac

Mac players report it runs

A Mac player reported it running through Highball (M2 2026-10-11); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Plays, but the frame rate falls steeply once the shooting starts and particles fly, in every graphics mode the reporter tried, with menus at 60 fps and occasional hitches when scrolling the map. Playable since the game is turn based. The Mac version on Steam is 32-bit and does not run on current macOS, so the Windows version is the one to use.

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
