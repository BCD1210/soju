Baldur's Gate 3 on Mac

Has a Mac version

Larian ships a native Mac version on Steam and GOG. Use that; it does not need Soju.

Linux (Proton) reference: 482 of 510 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

A Mac player reported it running through Highball (4/5) (M5 2026-10-27); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: native mac build exists — prefer it; Wine works too. Reported playable through Highball in DirectX 11 mode with DXMT on the Wine 11 engine on an M5 (GOG edition), apart from the picture stretching when the aspect ratio was changed.

Mac data: Highball database (CC0).
