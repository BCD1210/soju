EA SPORTS FC 25 on Mac

Does not run: anti-cheat

Its anti-cheat (EA anticheat) runs as a Windows kernel driver, which Wine cannot run, so it does not run on a Mac this way. The Linux numbers below are for Proton, where some anti-cheat is allowed.

Linux (Proton) reference: 0 of 7 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).
