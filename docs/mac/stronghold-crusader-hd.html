Stronghold Crusader HD on Mac

Mac players report it runs

A Mac player reported it running through Highball (4/5) (M2 2026-11-09); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Playable on an M2 on the Wine 11 engine r28 in a one minute session, so it covers the start only.

Linux (Proton) reference: 11 of 13 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
