HELLDIVERS™ 2 on Mac

Does not run: anti-cheat

Highball's database lists it as blocked (anti-cheat or publisher). Not run in Soju yet; Soju's engines differ, so results can too. Their notes: DirectX 12 only, so it needs Apple's D3DMetal (Play offers the licence) and the Wine 11 engine (CrossOver 26.3 tree), which is where CrossOver users play it. Its first check is the CPU: it requires AVX2 and refuses to start with 'Incompatible CPU detected' unless AVX is advertised through Rosetta, which the recipe does.
