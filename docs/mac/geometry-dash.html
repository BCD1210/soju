Geometry Dash on Mac

Mac players report it runs

A Mac player reported it running through Highball (5/5) (M2 2026-10-08); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: This game has a native macOS version on Steam, so the Mac Steam app runs it directly without Highball. That is the better way to play it. The Windows build was reported working through Highball over a 2-minute session, with a low frame rate. It draws with OpenGL, which Highball's graphics modes don't change, so the page sets no mode. A second player rates it perfect after two hours on an M2.

Linux (Proton) reference: 190 of 202 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
