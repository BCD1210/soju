Call of Duty (Black Ops, Warzone) on Mac

Does not run: anti-cheat

Activision's Ricochet anti-cheat uses a Windows kernel driver, which Wine cannot run, so these games do not start online under Wine on any Mac or Linux setup. Cloud services (GeForce NOW, Xbox Cloud Gaming) are the way to play them on a Mac.
