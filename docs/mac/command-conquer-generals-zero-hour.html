Command & Conquer™ Generals Zero Hour on Mac

Mac players report it runs

A Mac player reported it running through Highball (M2 Pro 2026-10-09); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: The game stopped with a message that it needs DirectX 8 or later. Generals shows that when it cannot use the screen resolution it picked, and Mac screens have sizes it does not expect. Setting Resolution = 1280 720 in Options.ini (Documents, Command and Conquer Generals Zero Hour Data, create the file with that line if it is missing) is the usual fix, and Emulate display mode changes on the game's page can help.…

Linux (Proton) reference: 13 of 17 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
