Dead by Daylight on Mac

Does not run: anti-cheat

Highball's database lists it as blocked (anti-cheat or publisher). Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Anti-cheat: Easy Anti-Cheat. The game refuses to start without the anti-cheat's kernel driver, which cannot run under Wine on macOS, so no mode or engine changes this. The reporter saw the anti-cheat block on an M5.

Linux (Proton) reference: 387 of 429 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).
