Resident Evil Village on Mac

Mac players report it runs

A Mac player reported it running through Highball (M5 2026-09-18); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: RE Engine, Direct3D 12 only, so D3DMetal. Two things happen on a first launch. First, Capcom's own first-run notice, a small 'CAPCOM InstallerMessage' window saying a 'VIDEO CODEC: WMVideo Decoder' must be installed: it is an unconditional notice, not a check (the program has no codec or registry test in it), so tick 'I accept the above message' and press Exit, and Steam starts the game. How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
