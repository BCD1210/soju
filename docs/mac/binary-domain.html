Binary Domain on Mac

Mac players report it runs

A Mac player reported it running through Highball (M1 2026-10-05); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Gets in game with high frame rates once its configuration tool and the game run the same way, and the sound is broken. The game stores the graphics card's ID from BinaryDomainConfiguration.exe and refuses to start when the game sees another one. How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
