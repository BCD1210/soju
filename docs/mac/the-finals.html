Soju is a free, open-source app that installs the official Windows game launchers on Apple Silicon Macs.

THE FINALS on Mac

Does not run: anti-cheat

Its anti-cheat (Easy Anti-Cheat, Denuvo Anti-Cheat, AnyBrain) runs as a Windows kernel driver, which Wine cannot run, so it does not run on a Mac this way. The Linux numbers below are for Proton, where some anti-cheat is allowed.

Linux (Proton) reference: 616 of 824 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Anti-cheat data: Are We Anti-Cheat Yet? (MIT), via the Highball database.
