Black Mesa on Mac

Mac players report it runs

A Mac player reported it running through Highball (M5 Pro 2026-10-18); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Plays on the Wine 11 engine for the one player so far (M5 Pro, macOS 27.2) in Wine's own Direct3D, DXMT or Apple's DirectX 12 support, with some frame drops in heavy scenes, and the recipe makes Play offer that engine. How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
