How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Ubisoft Connect
soju ubisoft       # sign in, install the game, press Play

Or download the Soju app and add Ubisoft Connect under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
