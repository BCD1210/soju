Diablo II: Resurrected on Mac

Runs in Soju

Played in-game and online on an M4 Pro with macOS 26.5. Direct3D 12 through Apple's D3DMetal. Needs macOS 26.4 or later: the game requires AVX, which Rosetta 2 offers from 26.4.

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Battle.net
soju battlenet     # sign in, install the game, press Play

Or download the Soju app and add Battle.net under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.

Questions

Does Diablo II: Resurrected run on an Apple Silicon Mac?

Runs in Soju. Played in-game and online on an M4 Pro with macOS 26.5. Direct3D 12 through Apple's D3DMetal. Needs macOS 26.4 or later: the game requires AVX, which Rosetta 2 offers from 26.4.

How do I install Diablo II: Resurrected on a Mac?

Install the Windows Battle.net with Soju, a free open-source app, sign in, then install the game and press Play.
