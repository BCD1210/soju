BattleBit Remastered on Mac

Does not run: anti-cheat

Highball's database lists it as blocked (anti-cheat or publisher). Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Cannot work. BattleBit Remastered uses Easy Anti-Cheat, which loads a kernel driver on Windows, and Wine cannot run one. The Proton runtime that makes EAC work on Linux has no macOS build. The reporter also notes that the game's offline mode cannot be reached without the anti-cheat installed, so there is no way around it from inside the game either.

Linux (Proton) reference: 63 of 69 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).
