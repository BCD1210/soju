SpiritVale on Mac

Does not run: anti-cheat

Highball's database lists it as blocked (anti-cheat or publisher). Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Anti-cheat: Easy Anti-Cheat. Proton's EAC support works through a Linux-native runtime (easyanticheat_x64.so) that Proton loads beside the game; there is no such runtime for Wine on macOS and Wine cannot load Linux libraries, so the bootstrap fails here whatever the engine. Only Epic can change that.

Linux (Proton) reference: 5 of 5 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).
