Soju is a free, open-source app that installs the official Windows game launchers on Apple Silicon Macs.

Metaphor: ReFantazio on Mac

Runs on Mac (Highball test)

Highball's maintainer ran it on an Apple Silicon Mac (2026-09-12) with Highball's own Wine engine and dxmt. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: DirectX 11, Denuvo on the full game. Needs engine x64-crossover26.3-r8 or later: on every earlier engine the game does not reach play, and no setting changes that. Measured with the demo on r8, DXMT, 1728x1117: language and brightness prompts, the opening cutscenes, the title menu, New Game, the naming and difficulty prompts, the first dialogue and the run through the Tradia Desert prologue, 55 to 59 fps throughout…

Linux (Proton) reference: 72 of 78 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
