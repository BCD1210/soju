Command & Conquer: Red Alert™ 2 and Yuri’s Revenge™ on Mac

Mac players report it runs

A Mac player reported it running through Highball (5/5) (M3 2026-10-06); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: The game asks Windows for a display mode the Mac doesn't offer, Wine refuses, and the game stops with 'Error - unable to set video mode'. The reporter got it running with Emulate display mode changes on for the game (Wine pretends the mode changed and scales the picture) and the D3DMetal graphics mode, whose 32-bit DirectDraw is cnc-ddraw. How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
