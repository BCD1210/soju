How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose EA app
soju ea            # sign in, install the game, press Play

Or download the Soju app and add EA app under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.
