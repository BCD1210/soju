Prison Architect on Mac

Mac players report it runs

A Mac player reported it running through Highball (5/5) (M4 2026-09-30); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Reported perfect on DXVK on an M4 with the default engine r11 after 14 minutes, running the Windows build. The Steam version also includes a Mac build. Nothing was measured here.

Linux (Proton) reference: 16 of 16 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
