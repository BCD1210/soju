Gold Mining Simulator 2 Demo on Mac

Mac players report it runs

A Mac player reported it running through Highball (M2 Pro 2026-09-27); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Unreal Engine. The free singleplayer demo of Gold Mining Simulator 2 (full game Steam 2885380). Runs on D3DMetal with -dx12, which the game needs: without it it falls back to Direct3D 11 and crashes. Reported about 135 fps in the menu and about 30 fps in game at 1920x1080 windowed, all Low, 3D resolution 50%, 18 to 20 fps at 3440x1440. The game uses 11 to 13 GB of memory, so close other apps on a 16 GB Mac. Nothing…

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
