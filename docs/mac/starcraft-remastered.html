StarCraft: Remastered on Mac

Runs in Soju

Single-player match started and drew with the Remastered graphics on an M4 Pro with macOS 26.5. Multiplayer and sound not tested. Blizzard's own Mac build is an Intel build that runs through Rosetta 2.

DateRun on 2026-11-10, M4 Pro with macOS 26.5

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Battle.net
soju battlenet     # sign in, install the game, press Play

Or download the Soju app and add Battle.net under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

What you need

ItemDetail
MacApple Silicon. We ran it on an M4 Pro with macOS 26.5; other versions are untested.
AccountA Battle.net account. StarCraft itself is free there; the Remastered graphics are a paid upgrade, and our test account has them.
Apple's Game Porting ToolkitBattle.net in Soju uses it. Soju downloads Apple's files during setup and checks Apple's signature before installing them.
DiskAbout 5.5 GB for the game in our install, on top of Battle.net and the engine.

What we checked

  • Battle.net showed Update for an older install; the update finished and the button changed to Play.
  • The intro video played and a click skipped it.
  • The main menu came up signed in to Battle.net, version 1.23.10.
  • Single Player, Expansion, a new character name typed on the keyboard, Play Custom, a melee game on the Bottleneck map against one computer player.
  • The match loaded with the Remastered graphics: command centre, SCVs, minerals and the console all drew correctly.

What we did not check

  • Multiplayer and ladder games.
  • Sound.
  • Sessions longer than a few minutes.
  • Which graphics path the game uses under Wine.

Questions

Does StarCraft: Remastered run on an Apple Silicon Mac?

Runs in Soju. Single-player match started and drew with the Remastered graphics on an M4 Pro with macOS 26.5. Multiplayer and sound not tested. Blizzard's own Mac build is an Intel build that runs through Rosetta 2.

How do I install StarCraft: Remastered on a Mac?

Install the Windows Battle.net with Soju, a free open-source app, sign in, then install the game and press Play.
