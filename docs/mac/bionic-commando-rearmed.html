Bionic Commando: Rearmed on Mac

Mac players report it runs

A Mac player reported it running through Highball (5/5) (M2 Max 2026-10-17); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Runs once NVIDIA's PhysX System Software is in the environment, which the recipe now installs (the reporter of highball#375 and #428 confirmed it on an M2 Max, 2026-10-26). Without it the game crashed on launch on DXVK and on Wine's own Direct3D alike: it starts a second copy of itself, loads PhysX's loader and cooking DLLs from its folder but never PhysXCore, and raises its own fatal error. Nothing was measured…

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.
