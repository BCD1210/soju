Counter-Strike on Mac

Mac players report it runs

A Mac player reported it running through Highball (4/5) (M1 2026-09-27); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: The 2000 original (GoldSrc). Reported very playable on the default engine r11 in DXMT mode on an M1, below 60 fps but not needing it. Steam also sells a native Mac build of it, which Highball points out on the game's page since 0.9.39. Nothing was measured here. A second report rates it perfect after 10 minutes in wined3d mode on an M4 Pro. The game draws through OpenGL, which Wine hands to the Mac's own OpenGL…

Linux (Proton) reference: 28 of 34 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
