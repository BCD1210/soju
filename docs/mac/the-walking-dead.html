The Walking Dead on Mac

Mac players report it runs

A Mac player reported it running through Highball (M1 2026-10-26); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Telltale's 2012 game, the Steam one called The Walking Dead. Does not launch for the one report so far: right after starting, the game asks for a single block of about 2 GB, which no 32-bit program can get under Wine, and crashes when it doesn't get it. The graphics mode makes no difference, and Steam's DirectX setup did not help. Nothing was measured here beyond the memory probe described in the issue.

Linux (Proton) reference: 14 of 14 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
