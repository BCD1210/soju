Highball's maintainer ran it on an Apple Silicon Mac (M5 2026-09-11) with Highball's own Wine engine and dxmt. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Plays on engine x64-crossover26.3-r6 or later. The game uses its own Vulkan renderer (through MoltenVK), so the graphics mode setting does not apply to it; keep DXMT for the Rockstar launcher, which needs it. How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Rockstar Games Launcher
soju rockstar      # sign in, install the game, press Play

Or download the Soju app and add Rockstar Games Launcher under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
