FINAL FANTASY XIII on Mac

Mac players report it runs

A Mac player reported it running through Highball (4/5) (M4 2026-09-19); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: A two-minute session on wined3d rated playable with minor issues. The reporter runs the game with FF13Fix 1.6.4, a community patch for the PC port, because the start would not load without it. The minor issues, longer play and the frame rate are not recorded yet. The port is Direct3D 9, so DXVK is the other renderer worth trying.

Linux (Proton) reference: 21 of 22 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
