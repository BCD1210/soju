Soju is a free, open-source app that installs the official Windows game launchers on Apple Silicon Macs.

World of Warships on Mac

Does not run: anti-cheat

Highball's database lists it as blocked (anti-cheat or publisher). Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Wargaming ended World of Warships on macOS, and the Windows game refuses to start on a Mac: after the region choice it shows "Sorry, unsupported operating system: macOS support has been discontinued" and quits. It asks Wine which system it runs on and stops when the answer is macOS, so the graphics mode and the engine make no difference. The launcher itself works. The download is 84 GB.

Linux (Proton) reference: 61 of 66 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).
