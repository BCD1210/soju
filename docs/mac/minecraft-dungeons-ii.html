Minecraft Dungeons II on Mac

Mac players report it runs

A Mac player reported it running through Highball (4/5) (M1 2026-10-24); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Reported playable on the Wine 11 engine with DXMT on an M1. Signing in with a Microsoft account does not work, so capes cannot be redeemed, and everything else is available. The reporter says the sign-in needs an implementation of xgameruntime.dll, Microsoft's Gaming Runtime, which Wine does not have. Nothing was measured here.

Linux (Proton) reference: 99 of 243 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
