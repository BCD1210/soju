CloverPit on Mac

Runs on Mac (Highball test)

Highball's maintainer ran it on an Apple Silicon Mac (2026-10-07) with Highball's own Wine engine and dxmt. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Unity, Direct3D 11. The free demo (Steam 3347820) plays here on DXMT: the language picker, the epilepsy warning, the developers' note, the 3D main menu and the first run's slot-machine scene, all drawing and animating, on an M1 Pro with the default engine. No frame rate was measured. One report says the game freezes on launch in every mode (no chip, engine or log given). The demo's opening is three static screens…

Linux (Proton) reference: 60 of 69 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
