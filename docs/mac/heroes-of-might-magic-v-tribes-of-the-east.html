Heroes of Might & Magic V: Tribes of the East on Mac

Mac players report it runs

A Mac player reported it running through Highball (4/5) (M2 2026-10-26); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: The standalone expansion, a separate Steam app from Heroes of Might and Magic V. Reported to run like on Windows on an M2 with DXMT over almost two hours. The only problem was on the very first launch, when macOS asked whether Highball may use the Documents folder (the game keeps its profile and saves there) and the screen went black after the answer. Quitting with Command Option Escape and starting it again fixed…

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
