Soju is a free, open-source app that installs the official Windows game launchers on Apple Silicon Macs.

VRChat on Mac

Does not run: anti-cheat

Highball's database lists it as blocked (anti-cheat or publisher). Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Anti-cheat: Easy Anti-Cheat. On Windows it loads a kernel driver, which Wine cannot run, and the Linux route (EAC's own Proton runtime) does not exist for macOS, so the launch stops at 'Failed to load the anti-cheat module' on every engine and graphics mode. Linux/Proton status 'Supported' does not apply to macOS.

Linux (Proton) reference: 167 of 199 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).
