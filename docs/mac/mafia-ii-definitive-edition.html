Mafia II: Definitive Edition on Mac

Mac players report it runs

A Mac player reported it running through Highball (5/5) (M3 2026-10-21); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Reported perfect after a two-minute session on the default engine, the report naming DXMT as the renderer in a DXVK environment. The reporter turned PhysX off in the game's own settings and does not say what happens with it on. A short session, so it says the game starts and plays, not much more. Nothing was measured here.

Linux (Proton) reference: 26 of 27 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in Discord or send a compatibility report and this page gets updated.
