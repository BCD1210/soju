Soju is a free, open-source app that installs the official Windows game launchers on Apple Silicon Macs.

Diablo II: Resurrected – Infernal Edition on Mac

Mac players report it runs

A Mac player reported it running through Highball (M5 2026-10-17); not verified by Highball's maintainer. Not run in Soju yet; Soju's engines differ, so results can too. Their notes: Direct3D 12, so D3DMetal. Does not start on the default engine for the one report so far (no window, the process idle). Overwatch 2 behaves the same on Highball's engines, no window on the default engine and playable on the Wine 11 engine, which is the next thing to try here, with DXMT_ALLOW_CROSS_PROCESS_SWAPCHAIN=1 in the environment so Battle.net's own window does not crash there (the battle-net recipe sets it).

Linux (Proton) reference: 40 of 45 player reports from the last two years say it runs (ProtonDB, as of 2026-11-02, ODbL).

Mac data: Highball database (CC0).

How to try it with Soju

brew install BCD1210/soju/soju
soju install          # choose Steam (macOS 26 or later)
soju steam         # sign in, install the game, press Play

Or download the Soju app and add Steam under Platforms. Needs an Apple Silicon Mac (M1 or newer) and macOS 14 or later.

Tried it? Tell us in #compatibility on Discord or send a compatibility report and this page gets updated.
