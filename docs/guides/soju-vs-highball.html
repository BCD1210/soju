Soju vs Highball

Checked November 11, 2026

Both are free, open-source apps that run Windows games on Apple Silicon without a Windows licence. Highball is the larger project, built around an open compatibility database. Soju is built around the stores' own Windows launchers, Battle.net and Xbox PC included.

Which one fits

  • You play Blizzard games (Diablo IV, Diablo II: Resurrected, Overwatch 2, StarCraft): Soju. These are the games we have run through Battle.net.
  • You want the widest tested Steam catalogue and to check a game before downloading it: Highball. Its database is much larger than our list.
  • You have PC Game Pass or Microsoft Store games: Soju has an experimental path. Expect most games not to work yet.
  • You want both: they keep their files in separate folders and do not interfere with each other.

How the two relate

Soju uses Highball's work and says so. Soju's engine applies fourteen of Highball's Wine patches (audio dropouts at 48 kHz, surround sound on stereo speakers, in-game video and others), and Soju's game pages show results from Highball's CC0 database next to our own. Both projects build on Wine, CodeWeavers' published sources and Apple's Game Porting Toolkit.

What we have not done

  • We have not run the same game in both apps side by side, so this page makes no speed comparison.
  • The Highball column is from its README on November 11, 2026. It changes often; check its page for the current state.

Questions

Is Soju or Highball better for Diablo IV on a Mac?

Soju has run Diablo IV through Battle.net: with the free trial on an M4 Pro, a character was created and the game loaded into the first area. Highball's README says Battle.net shows its sign-in window and that no game has been played through it yet.

Are Soju and Highball both free?

Yes. Both are free and open source under GPL-3.0. Neither needs a Windows licence.

Can I install Soju and Highball on the same Mac?

Yes. Each keeps its engine and Windows environments in its own folder, so they do not interfere with each other.

Does Soju use Highball's code?

Soju's engine applies fourteen Wine patches from Highball's engine repository, and Soju's game pages show results from Highball's open database. Both are credited in Soju's repository.
