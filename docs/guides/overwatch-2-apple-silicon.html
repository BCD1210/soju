Overwatch 2 on Apple Silicon

Overwatch 2 has no Mac version. It runs through the Windows Battle.net client that Soju sets up: on an M4 Pro with macOS 26.5 the game started, signed in and reached its online main menu, drawn with Apple's D3DMetal.

The quick version

brew install BCD1210/soju/soju
soju install          # choose Battle.net
soju update           # 1.13.0 or later adds the driver shims Overwatch 2 needs
soju battlenet        # sign in, install Overwatch, press Play

Or download the Soju app, open Platforms and choose Battle.net.

What you need

ItemDetail
MacApple Silicon. Checked on an M4 Pro with macOS 26.5; other Macs are untested.

Apple's Game Porting ToolkitAll of Apple's shims, including atidxx64.dll and nvapi64.dll. Soju 1.13.0 adds them with soju update; soju doctor says if they are missing.
DiskAbout 85 GB for the game, as Battle.net reported it.

General Error (0xE0010110)

If Overwatch 2 shows General Error (0xE0010110) right after you press Play, the engine is missing Apple's AMD driver shim. The game loads atidxx64.dll while it sets up graphics; engines set up from an older toolkit, or by Soju before 1.13.0, had only the d3d11, d3d12 and dxgi shims. Close Battle.net and run:

soju update     # or: soju gptk
soju doctor     # should report atidxx64.dll and nvapi64.dll as Apple's shims

What we checked

  • Battle.net installed the game after the phone number was added to the account.
  • Without the shims the game stopped with General Error (0xE0010110). With them it loaded, signed in and showed the main menu online, with the season and pass screens.
  • Diablo II: Resurrected still reached its title screen on the same engine after the change.

What we did not check

  • A match, the practice range, frame rate in play, or voice chat.
  • Long sessions.
  • Other Macs and macOS versions.

Played a match on your Mac? Turn on Show FPS in games under Platforms and tell us the number in #compatibility on Discord or in a compatibility report; it goes on the Overwatch 2 page.

Questions

Does Overwatch 2 run on Apple Silicon Macs?

Through the Windows Battle.net client that Soju installs, Overwatch 2 reached its main menu, signed in and online, on an M4 Pro with macOS 26.5, drawn with Apple's D3DMetal. A match was not played in that check.

How do I fix General Error (0xE0010110) in Overwatch 2 on a Mac?

The game loads atidxx64.dll, Apple's AMD driver shim from the Game Porting Toolkit. When the Wine engine has only Apple's d3d11, d3d12 and dxgi shims, Overwatch 2 stops with this error at start. In Soju, run soju update (1.13.0 or later) or soju gptk to add the missing shims, then start the game again.

Why does Battle.net ask for a phone number before installing Overwatch 2?

Blizzard requires a phone number on the Battle.net account before the free game can be installed. Add it on account.battle.net under Security; the install button appears afterwards.
