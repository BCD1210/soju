이 가이드는 Soju 오픈소스 게임 런처 도구의 사용 사례입니다. Battle.net·Steam·Epic·GOG 설치와 지원 범위는 메인 페이지에서 확인하세요.

맥에서 디아블로 II: 레저렉션 돌리기

Soju로 Apple Silicon 맥에서 Battle.net판 디아블로 II: 레저렉션을 설치하고 실행하는 방법입니다. macOS 26.4 이상과 본인의 게임 라이선스가 필요합니다. M4 Pro / macOS 26.5에서 온라인 플레이를 확인했으며, 다른 환경의 결과는 달라질 수 있습니다.

문서 업데이트: 2026년 9월 20일. 시작 전 soju doctor d2r로 확인하세요. macOS가 낮으면 먼저 업데이트하고 재시동하세요. Soju나 AVX 환경변수 설정만으로 운영체제의 Rosetta 수정을 대체할 수 없습니다. #44에서 macOS 26.0.1 실행 멈춤 제보와 후속 진행을 확인할 수 있습니다.

빠른 설치

brew install BCD1210/soju/soju
soju install      # 엔진 + 애플 GPTK 안내 + 배틀넷 자동 설치
soju battlenet    # 로그인 후 앱에서 디아2 설치 → 플레이

Homebrew가 없다면:

curl -fsSL https://raw.githubusercontent.com/BCD1210/soju/main/install.sh | bash

왜 맥에서 디아2가 안 됐던 걸까

1. 실행하면 영원히 멈춤 (메모리 86MB에서 정지)

디아2 로더는 AVX 명령어를 요구합니다. 로제타2는 AVX를 지원하지만, 비공개 환경변수 ROSETTA_ADVERTISE_AVX=1을 설정해야만 프로세스에 AVX를 "광고"합니다. 이게 없으면 그래픽 초기화 전에 무한 대기합니다. 크로스오버는 이걸 런처에서 몰래 설정하기 때문에 되고, 무료 래퍼들은 안 됐던 겁니다.

2. 배틀넷 로그인 후 BLZBNTBNA00000005 에러

배틀넷 Agent는 접속한 프로세스의 서명을 검증하는데, 이때 PID를 전체 실행파일 경로로 변환해야 합니다. 맥에는 /proc이 없어서 맥 전용 코드가 필요한데, 커뮤니티 wine 빌드 대부분엔 이게 없습니다. Soju 엔진은 코드위버스가 공개한 크로스오버 GPL 소스로 빌드해서 이 문제가 없습니다.

3. 그래픽 크래시 루프

애플 게임 포팅 툴킷(GPTK) 라이브러리는 반드시 심링크 구조로 배치해야 합니다. 복사하면 @loader_path가 어긋나 어설션 루프로 죽습니다. Soju가 자동으로 처리합니다.

준비물

  • 애플 실리콘 맥 (M1 이상)
  • macOS 26.4 이상 필수. 2026년 블리자드 안티치트 업데이트가 로제타 버그를 유발했고, 애플이 26.4에서 수정했습니다
  • 로제타2: softwareupdate --install-rosetta
  • 본인 배틀넷 계정 + 디아2 레저렉션 소지

합법인가요?

네. 엔진은 코드위버스가 공개한 GPL 소스를 컴파일한 것이고, GPTK는 애플이 비상업 배포를 허용한 원본 파일을 그대로 받아 쓰며, 게임은 본인 배틀넷 계정으로 정식 서버에 접속합니다. 크랙·에뮬레이션이 아닙니다.

자주 묻는 질문

맥에서 디아블로 II: 레저렉션이 실행하자마자 멈추는 이유는?

디아2 로더는 AVX 명령어가 필요합니다. Rosetta 2는 AVX를 지원하지만 ROSETTA_ADVERTISE_AVX=1이 설정된 프로세스에만 알려 줍니다. 이 값이 없으면 로더가 메모리 약 86MB, CPU 0% 상태로 계속 기다립니다. 소주는 게임을 실행할 때 이 값을 넣습니다. macOS 26.4보다 낮은 버전에서는 애플이 26.4에서 고친 Rosetta 2 버그 때문에 그래도 멈출 수 있습니다.

CrossOver 없이 맥에서 디아2 레저렉션을 할 수 있나요?

네. 소주는 무료 오픈소스이고, M4 Pro와 macOS 26.5에서 배틀넷 온라인 플레이를 확인했습니다. 애플 실리콘 맥, macOS 26.4 이상, 본인 배틀넷 계정과 디아2 라이선스가 필요합니다.

배틀넷에서 BLZBNTBNA00000005 오류가 나는 이유는?

배틀넷 Agent가 접속한 프로그램의 서명을 확인하지 못해서입니다. 프로세스 번호로 파일 경로를 찾는 맥 전용 코드가 필요한데, 대부분의 커뮤니티 Wine 빌드에는 없습니다. 소주의 엔진은 코드위버스가 공개한 소스로 빌드해서 이 코드가 들어 있습니다.

애플 ID나 게임 포팅 툴킷 dmg가 필요한가요?

아니요. 소주 1.10.13부터는 설치할 때 애플 게임 포팅 툴킷 파일을 받아 애플 서명을 확인한 뒤 설치합니다. 애플에서 직접 받은 dmg를 마운트해 두면 그것을 씁니다.
