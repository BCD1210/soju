Soju by Didim Labs 디아2 가이드 소주 소개 GitHub

이 글은 소주(Soju) 안내의 일부입니다. 소주는 애플 실리콘 맥에 윈도우용 배틀넷, 스팀, 에픽, GOG, Xbox PC 런처를 설치해 주는 무료 오픈소스 맥 앱입니다.

맥에서 스타크래프트: 리마스터 하기

스타크래프트: 리마스터는 소주가 설치하는 윈도우용 배틀넷으로 실행됩니다. M4 Pro, macOS 26.5에서 배틀넷으로 게임을 업데이트하고, 인트로 영상을 보고, 로그인된 메인 메뉴를 거쳐 컴퓨터 상대 싱글 대전을 시작하는 것까지 확인했습니다.

짧게 요약

brew install BCD1210/soju/soju
soju install          # Battle.net 선택 (애플 게임 포팅 툴킷 필요)
soju battlenet        # 로그인하고 스타크래프트를 설치한 뒤 플레이

터미널이 싫으면 소주 앱을 받아 Platforms에서 Battle.net을 고르고 게임 포팅 툴킷을 추가하면 됩니다. 스타크래프트를 설치하면 소주 라이브러리에도 나타나고, 터미널에서는 soju game battlenet:s1로 바로 실행됩니다.

준비물

항목내용
맥애플 실리콘. M4 Pro, macOS 26.5에서 확인했고 다른 버전은 확인하지 못했습니다.
계정배틀넷 계정. 스타크래프트 자체는 무료이고 리마스터 그래픽은 유료입니다. 시험한 계정은 리마스터를 보유하고 있습니다.
애플 게임 포팅 툴킷소주의 배틀넷이 사용합니다. 무료 애플 ID로 직접 받아야 하고, 받은 파일은 소주가 엔진에 설치합니다.
용량게임만 약 5.5GB. 배틀넷과 엔진은 별도입니다.

확인한 것

  • 예전에 설치해 둔 게임이라 배틀넷에 업데이트 버튼이 떴고, 업데이트가 끝나자 플레이로 바뀌었습니다.
  • 인트로 영상이 재생됐고 클릭으로 넘어갔습니다.
  • 배틀넷에 로그인된 상태로 메인 메뉴가 떴습니다. 버전은 1.23.10입니다.
  • 싱글 플레이, 브루드워, 키보드로 캐릭터 이름 입력, 사용자 지정 게임, Bottleneck 맵에서 컴퓨터 1명과 밀리 대전.
  • 리마스터 그래픽으로 커맨드 센터, SCV, 미네랄, 하단 조작판이 모두 정상으로 그려졌습니다.

확인하지 못한 것

  • 멀티플레이와 래더
  • 소리
  • 몇 분 이상 이어지는 플레이
  • Wine에서 어떤 그래픽 경로로 도는지
