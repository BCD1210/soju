소주 by Didim Labs 디아2 가이드 오버워치 2 가이드 게임 목록 디스코드

이 가이드는 애플 실리콘 맥에 윈도우용 배틀넷·스팀·에픽·GOG·EA·락스타·유비소프트 런처를 설치하는 무료 오픈소스 앱 소주의 안내서입니다.

맥북에서 디아블로 4 하기

디아블로 4는 맥 버전이 없습니다. 소주가 설치한 윈도우 배틀넷으로 돌리면, M4 Pro·macOS 26.5에서 무료 체험판이 실행되고 오프닝 영상, 캐릭터 생성, 첫 지역 진입까지 됐습니다. 그래픽은 애플 D3DMetal로 그립니다.

빠른 설치

brew install BCD1210/soju/soju
soju install          # Battle.net 선택
soju battlenet        # 로그인 → 디아블로 4 → Try For Free(또는 Install) → Play

또는 소주 앱을 받아 Platforms에서 Battle.net을 고릅니다.

필요한 것

항목내용
맥애플 실리콘. M4 Pro, macOS 26.5에서 확인했고 다른 맥은 확인하지 못했습니다.
계정배틀넷 계정. 무료 체험판은 구매 없이 됩니다. 레벨 제한과 제공 기간은 블리자드가 정합니다.
애플 GPTK소주가 설치할 때 받아 옵니다. 빠진 것이 있으면 soju doctor가 알려 줍니다.
용량배틀넷 표시 기준 고해상도 에셋 제외 97.4GB, 포함 181GB. 설치 화면에서 High-Resolution Assets 체크를 풀면 줄어듭니다.

설치 순서

  1. 배틀넷 게임 줄에서 디아블로 4를 고르고 Try For Free를 누릅니다(구매했다면 Install).
  2. 두 번째 설치 화면에서 공간이 넉넉하지 않으면 High-Resolution Assets 체크를 풉니다.
  3. 다운로드가 끝나기 전에 Play가 켜집니다. 여기서는 73%쯤에서 켜졌고, 나머지를 받는 동안 게임이 실행됐습니다.

게임은 전체 화면으로 열립니다. 처음에 스크린 리더, 밝기, 접근성 설정을 묻고, 이어서 오프닝 영상이 몇 분 동안 나옵니다.

확인한 것

  • 배틀넷에서 체험판을 설치하고 게임을 실행했습니다.
  • 설정 화면, 자막이 나오는 오프닝 영상, 직업 선택, 캐릭터 생성이 모두 정상으로 그려졌습니다.
  • 첫 지역(Icehowl Taiga)에 들어가 인터페이스, 미니맵, 퀘스트가 표시됐고 캐릭터가 움직였습니다.

확인하지 않은 것

  • 소리, 프레임, 전투, 장시간 플레이
  • 다른 사람과 함께 하는 플레이, 체험판 범위를 넘는 본편
  • 다른 맥과 다른 macOS 버전

맥에서 더 해 보셨다면 소주의 게임 상세 창에서 Show FPS를 켜고 나온 숫자를 디스코드 한국어 채널이나 호환성 제보로 알려 주세요. 디아블로 4 페이지에 올립니다.

자주 묻는 질문

맥북(애플 실리콘)에서 디아블로 4 되나요?

소주가 설치한 윈도우 배틀넷으로 M4 Pro, macOS 26.5에서 실행했습니다. 오프닝 영상이 나오고, 캐릭터를 만들고, 첫 지역에 들어가 캐릭터가 움직이는 것까지 확인했습니다. 그래픽은 애플 D3DMetal입니다. 소리, 프레임, 장시간 플레이는 확인하지 않았습니다.

디아블로 4를 사지 않고 맥에서 해 볼 수 있나요?

블리자드가 무료 체험판을 제공하는 동안은 됩니다. 배틀넷에서 디아블로 4를 열고 Try For Free를 누릅니다. 체험판은 블리자드가 정한 레벨까지만 할 수 있습니다.

맥에서 디아블로 4 용량은 얼마나 되나요?

배틀넷이 표시한 용량은 고해상도 에셋 포함 181GB, 제외 97.4GB입니다. 다운로드가 73%쯤 됐을 때 Play 버튼이 켜졌습니다.
