소주 by Didim Labs 디아2 가이드 스타크래프트 가이드 게임 목록 디스코드

이 가이드는 애플 실리콘 맥에 윈도우용 배틀넷·스팀·에픽·GOG·EA·락스타·유비소프트 런처를 설치하는 무료 오픈소스 앱 소주의 안내서입니다.

맥북에서 오버워치 2 하기

오버워치 2는 맥 버전이 없습니다. 소주가 설치한 윈도우 배틀넷으로 돌리면, M4 Pro·macOS 26.5에서 로그인한 채 온라인 메인 메뉴까지 떴습니다. 그래픽은 애플 D3DMetal로 그립니다.

빠른 설치

brew install BCD1210/soju/soju
soju install          # 배틀넷 선택
soju update           # 1.13.0 이상: 오버워치 2에 필요한 드라이버 흉내 파일 추가
soju battlenet        # 로그인 → 오버워치 설치 → 플레이

또는 소주 앱을 받고 Platforms에서 Battle.net을 고르세요.

필요한 것

항목내용
맥애플 실리콘. M4 Pro·macOS 26.5에서 확인했고 다른 맥은 아직입니다.
계정휴대폰 번호가 등록된 배틀넷 계정. 블리자드가 무료 설치 전에 요구합니다(account.battle.net → 보안).
애플 GPTKatidxx64.dll, nvapi64.dll까지 포함한 전체 파일. 소주 1.13.0의 soju update가 채워 주고, 빠져 있으면 soju doctor가 알려 줍니다.
저장 공간배틀넷 기준 약 85GB

General Error (0xE0010110)

플레이를 누르자마자 General Error (0xE0010110)이 뜨면 엔진에 애플의 AMD 드라이버 흉내 파일이 없는 겁니다. 예전 GPTK나 1.13.0 이전 소주로 설치한 엔진에는 d3d11·d3d12·dxgi 세 개만 있었습니다. 배틀넷을 끄고 실행하세요.

soju update     # 또는 soju gptk
soju doctor     # atidxx64.dll, nvapi64.dll이 애플 파일로 나오면 정상

확인한 것

  • 계정에 휴대폰 번호를 등록한 뒤 배틀넷에서 설치됨
  • 파일이 없을 때는 General Error (0xE0010110)로 멈췄고, 채운 뒤에는 로그인·온라인 메인 메뉴·시즌 화면까지 뜸
  • 같은 엔진에서 디아블로 2 레저렉션도 그대로 타이틀 화면까지 뜸

확인 안 한 것

  • 실제 경기, 연습장, 플레이 중 프레임, 음성 채팅
  • 오래 플레이했을 때
  • 다른 맥과 macOS 버전

맥에서 경기를 해 보셨다면 Platforms의 Show FPS in games를 켜고 나온 숫자를 디스코드 한국어 채널이나 호환성 보고로 알려 주세요. 오버워치 2 페이지에 반영합니다.

자주 묻는 질문

맥북(애플 실리콘)에서 오버워치 2 되나요?

소주가 설치한 윈도우 배틀넷으로 M4 Pro, macOS 26.5에서 로그인한 채 온라인 메인 메뉴까지 떴습니다. 그래픽은 애플 D3DMetal입니다. 이번 확인에서 실제 경기는 해 보지 않았습니다.

General Error (0xE0010110)은 어떻게 고치나요?

엔진에 atidxx64.dll이 없어서 생깁니다. 소주 1.13.0 이상에서 soju update나 soju gptk를 실행하세요.

설치 전에 휴대폰 번호를 왜 등록하라고 하나요?

블리자드가 무료 설치 전에 요구합니다. account.battle.net 보안 메뉴에서 등록하면 설치 버튼이 나옵니다.
