StarCraft: Remastered on Apple Silicon

StarCraft: Remastered runs through the Windows Battle.net client that Soju sets up. On an M4 Pro with macOS 26.5 we updated the game in Battle.net, watched the intro, reached the main menu signed in, and started a single-player match against the computer.

Blizzard also offers StarCraft: Remastered in Battle.net for Mac. That build is made for Intel Macs and runs through Rosetta 2 on Apple Silicon. This guide covers the Windows client, which sits next to your other Windows Battle.net games in Soju.

The quick version

brew install BCD1210/soju/soju
soju install          # choose Battle.net
soju battlenet        # sign in, install StarCraft, press Play

Or download the Soju app, open Platforms and choose Battle.net. Once StarCraft is installed it also shows up in Soju's library, and soju game battlenet:s1 starts it from a terminal.

What you need

ItemDetail
MacApple Silicon. We ran it on an M4 Pro with macOS 26.5; other versions are untested.
AccountA Battle.net account. StarCraft itself is free there; the Remastered graphics are a paid upgrade, and our test account has them.
Apple's Game Porting ToolkitBattle.net in Soju uses it. Soju downloads Apple's files during setup and checks Apple's signature before installing them.
DiskAbout 5.5 GB for the game in our install, on top of Battle.net and the engine.

What we checked

  • Battle.net showed Update for an older install; the update finished and the button changed to Play.
  • The intro video played and a click skipped it.
  • The main menu came up signed in to Battle.net, version 1.23.10.
  • Single Player, Expansion, a new character name typed on the keyboard, Play Custom, a melee game on the Bottleneck map against one computer player.
  • The match loaded with the Remastered graphics: command centre, SCVs, minerals and the console all drew correctly.

What we did not check

  • Multiplayer and ladder games.
  • Sound.
  • Sessions longer than a few minutes.
  • Which graphics path the game uses under Wine.

Questions

Does StarCraft: Remastered run on Apple Silicon Macs?

Yes. Through the Windows Battle.net client that Soju installs, a single-player match started and rendered with the Remastered graphics on an M4 Pro with macOS 26.5. Multiplayer was not tested. Blizzard's own Mac build is an Intel build that runs through Rosetta 2.

Is StarCraft free to play on a Mac this way?

StarCraft itself is free on Battle.net and the Remastered graphics are a paid upgrade. Soju is free and open source.

How do I start StarCraft from Soju?

Install Battle.net from Soju's Platforms page or with soju install, sign in, install StarCraft and press Play. After that it appears in Soju's library, and soju game battlenet:s1 starts it from a terminal.
