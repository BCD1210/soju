Soju provides setup tools and launcher-specific Mac apps. You use each store's own interface and library.

Choose your launchers. Get set up.

The installer offers any combination of the four launchers and creates their shortcuts in ~/Applications.

curl -fsSL https://soju.snack-wrap.com/install.sh | bash

Or install the CLI through Homebrew:

brew install BCD1210/soju/soju
soju install

Use soju doctor to check your setup and soju update to update it. Homebrew-managed scripts update through brew upgrade soju.

Before you begin: Apple Silicon, Rosetta 2, Xcode Command Line Tools and Homebrew. The Battle.net, Epic and GOG setup uses Apple's Game Porting Toolkit, downloaded separately with an Apple ID. The tools are free; games and store accounts are your own.

Open source, from setup to fixes.

Soju's scripts and documentation are open source. Its Wine engine is built from CodeWeavers' published sources. Battle.net, Epic and GOG share that engine; Steam uses a separate wine-stable setup with DXMT for supported D3D11 games.

Apple's proprietary D3DMetal/GPTK components are a separate download, and the store clients remain their publishers' software. Soju does not bundle them.

The diagnosis notes and Steam implementation notes explain the fixes so others can inspect and reuse the work.
