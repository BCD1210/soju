What it does

Real launchers

Battle.net, Epic and GOG share a Wine engine built from CodeWeavers' sources with Apple's D3DMetal. EA, Rockstar and Ubisoft run on a copy of it with DXMT. Steam gets its own Wine 11 setup with DXMT for D3D11 games.

One library

Finds installed games across every launcher and imports the games you own on Steam and GOG.

Store search

Searches Steam, GOG and Microsoft Store listings with prices for your region.

Xbox PC

Experimental: imports owned and Game Pass games and downloads them through the Xodus backend.

Logins, purchases and game updates stay with each store. Soju doesn't bundle games or store clients, and it downloads Apple's Game Porting Toolkit files during setup.

Install

  1. Download the app

    Soju-1.13.1-macos-arm64.zip. Unzip it and move Soju to Applications. Signing notes.

  2. Pick launchers

    Open Soju, go to Platforms and choose the launchers you use. Battle.net, Epic and GOG also use Apple's Game Porting Toolkit; Soju downloads Apple's files and checks Apple's signature before installing them.

  3. Sign in and play

    Sign in inside each launcher as usual. Installed games show up in the library.

Prefer the terminal? Run the installer, or use Homebrew. You'll need Rosetta 2, the Xcode Command Line Tools and Homebrew.

curl -fsSL https://didimlabs.com/install.sh | bash

# or
brew install BCD1210/soju/soju
soju install

soju doctor checks the setup; soju update updates it.

FAQ

Can I play Windows games on an M1, M2, M3 or M4 Mac with Soju?

Often, yes. Soju runs the Windows launchers through Wine with Apple's D3DMetal or DXMT. Diablo II: Resurrected, Hogwarts Legacy and Guilt Free have been played on an M4 Pro with macOS 26.5. Games with kernel anti-cheat do not run.

Is Soju free?

Yes. Soju is free and open source under GPL-3.0-or-later. You buy games from the stores as usual. Didim Labs also sells its own Mac games in Soju's store tab.

Which macOS version do I need?

The Soju app needs macOS 14 or later on Apple Silicon. Steam games need macOS 26 or later, and Diablo II: Resurrected needs macOS 26.4 or later.

Is Soju a Whisky or CrossOver alternative?

It covers similar ground. Whisky is no longer developed and CrossOver is paid. Soju is free, focuses on the official store launchers, and builds its Wine engine from CodeWeavers' published sources.

Does Soju need my store passwords?

No. You sign in inside each official launcher. Library imports stay on your Mac and Soju has no account of its own.

A game won't start. What now?

Run soju doctor (or soju doctor d2r), check the guides, then open an issue with the game, your Mac, macOS version and what you see.
