소주는 애플 실리콘 맥에 공식 윈도우 게임 런처를 설치하는 무료 오픈소스 앱입니다.

스타크래프트 리마스터 맥에서 하기

소주에서 됨

M4 Pro, macOS 26.5에서 싱글 플레이 경기가 리마스터 그래픽으로 시작됐습니다. 멀티플레이와 소리는 확인 안 했습니다. 블리자드 자체 맥 버전은 인텔용이라 로제타 2로 돕니다.

자세한 가이드

런처Battle.net
상태소주에서 됨
날짜2026-11-10, M4 Pro · macOS 26.5에서 실행

소주로 해 보는 방법

brew install BCD1210/soju/soju
soju install          # Battle.net 선택
soju battlenet     # 로그인 → 게임 설치 → 플레이

또는 소주 앱을 받아 플랫폼에서 Battle.net을(를) 설치하세요. 애플 실리콘(M1 이상), macOS 14 이상이 필요합니다.

준비물

항목내용
맥애플 실리콘. M4 Pro, macOS 26.5에서 확인했고 다른 버전은 확인하지 못했습니다.
계정배틀넷 계정. 스타크래프트 자체는 무료이고 리마스터 그래픽은 유료입니다. 시험한 계정은 리마스터를 보유하고 있습니다.
애플 게임 포팅 툴킷소주의 배틀넷이 사용합니다. 설치할 때 소주가 애플 파일을 받아 애플 서명을 확인한 뒤 설치합니다.
용량게임만 약 5.5GB. 배틀넷과 엔진은 별도입니다.

확인한 것

  • 예전에 설치해 둔 게임이라 배틀넷에 업데이트 버튼이 떴고, 업데이트가 끝나자 플레이로 바뀌었습니다.
  • 인트로 영상이 재생됐고 클릭으로 넘어갔습니다.
  • 배틀넷에 로그인된 상태로 메인 메뉴가 떴습니다. 버전은 1.23.10입니다.
  • 싱글 플레이, 브루드워, 키보드로 캐릭터 이름 입력, 사용자 지정 게임, Bottleneck 맵에서 컴퓨터 1명과 밀리 대전.
  • 리마스터 그래픽으로 커맨드 센터, SCV, 미네랄, 하단 조작판이 모두 정상으로 그려졌습니다.

확인하지 못한 것

  • 멀티플레이와 래더
  • 소리
  • 몇 분 이상 이어지는 플레이
  • Wine에서 어떤 그래픽 경로로 도는지
