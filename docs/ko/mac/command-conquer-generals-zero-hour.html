맥 사용자 보고: 됨

맥 사용자가 Highball로 실행된다고 보고했습니다 (M2 Pro 2026-10-09). Highball 관리자 검증 전입니다. 소주에서는 아직 실행하지 않았고 엔진이 달라 결과가 다를 수 있습니다. 메모(영문): The game stopped with a message that it needs DirectX 8 or later. Generals shows that when it cannot use the screen resolution it picked, and Mac screens have sizes it does not expect. Setting Resolution = 1280 720 in Options.ini (Documents, Command and Conquer Generals Zero Hour Data, create the file with that line if it is missing) is the usual fix, and Emulate display mode changes on the game's page can help.…

런처Steam
상태맥 사용자 보고: 됨
날짜2026-11-11 갱신

소주로 해 보는 방법

brew install BCD1210/soju/soju
soju install          # Steam 선택 (macOS 26 이상)
soju steam         # 로그인 → 게임 설치 → 플레이

또는 소주 앱을 받아 플랫폼에서 Steam을(를) 설치하세요. 애플 실리콘(M1 이상), macOS 14 이상이 필요합니다.

해 보셨나요? 디스코드 한국어 채널나 호환성 보고로 알려 주시면 이 페이지에 반영합니다.
