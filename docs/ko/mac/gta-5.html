GTA 5 맥에서 하기

온라인은 안티치트로 막힘

GTA 온라인은 2024년 9월 배틀아이 안티치트를 넣은 뒤 Wine·Proton을 막아서 온라인은 안 됩니다. 스토리 모드는 소주에서 아직 실행해 보지 않았습니다. 소주의 락스타 게임즈 런처나 스팀에서 설치합니다.

리눅스(Proton) 참고: 최근 2년 사용자 보고 141건 중 97건이 실행된다고 했습니다 (ProtonDB, 2026-11-02 기준, ODbL).

Highball 관리자가 애플 실리콘 맥 M1 2026-09-09에서 자체 Wine 엔진 dxmt으로 직접 실행했습니다. 소주에서는 아직 실행하지 않았고 엔진이 달라 결과가 다를 수 있습니다. 메모(영문): Story mode plays. Needs engine x64-crossover26.3-r5 or later and the DXMT renderer. Launch it from Steam: Steam starts the Rockstar Games Launcher, which signs in and hands off to the game. The row passes -nobattleye on the Steam command line, the story-mode path: without it a fresh launcher profile starts GTA5_BE.exe and BattlEye's installer asks for its kernel driver, which cannot run under Wine (seen on an M4,…

맥 자료: Highball database (CC0).

소주로 해 보는 방법

brew install BCD1210/soju/soju
soju install          # Rockstar Games Launcher 선택
soju rockstar      # 로그인 → 게임 설치 → 플레이

또는 소주 앱을 받아 플랫폼에서 Rockstar Games Launcher을(를) 설치하세요. 애플 실리콘(M1 이상), macOS 14 이상이 필요합니다.
