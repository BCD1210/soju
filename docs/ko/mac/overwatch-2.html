소주는 애플 실리콘 맥에 공식 윈도우 게임 런처를 설치하는 무료 오픈소스 앱입니다.

오버워치 2 맥에서 하기

소주에서 됨

M4 Pro, macOS 26.5에서 로그인한 채 온라인 메인 메뉴까지 떴습니다. 그래픽은 D3DMetal(애플 GPTK)입니다. GPTK의 AMD·NVIDIA 드라이버 흉내 파일(atidxx64.dll, nvapi64.dll)이 있어야 하고, 없으면 시작하자마자 "General Error (0xE0010110)"로 멈춥니다. soju update가 채워 줍니다. 무료 설치 전에 배틀넷 계정에 휴대폰 번호를 등록해야 합니다. 이번 확인에서 실제 경기는 해 보지 않았습니다.

리눅스(Proton) 참고: 최근 2년 사용자 보고 870건 중 755건이 실행된다고 했습니다 (ProtonDB, 2026-11-02 기준, ODbL).

맥 사용자가 Highball로 실행된다고 보고했습니다 (3/5) (M5 Pro 2026-10-01). Highball 관리자 검증 전입니다. 소주에서는 아직 실행하지 않았고 엔진이 달라 결과가 다를 수 있습니다. 메모(영문): A player on an M5 Pro reports it plays flawlessly on the Wine 11 engine (highball#232), and the recipe makes Play offer that engine. On the Wine 11 engine (x64-crossover26.3-r12) the game opens and shows Blizzard's Battle.net account link screen, a QR code and a code to enter at blizzard.com/link, which a Steam player sees on a first start. The account was not linked here, so nothing past that screen was played. On…

맥 자료: Highball database (CC0).

스팀 상점 페이지

런처Battle.net
상태소주에서 됨
날짜2026-11-11, M4 Pro · macOS 26.5에서 실행

소주로 해 보는 방법

brew install BCD1210/soju/soju
soju install          # Battle.net 선택
soju battlenet     # 로그인 → 게임 설치 → 플레이

또는 소주 앱을 받아 플랫폼에서 Battle.net을(를) 설치하세요. 애플 실리콘(M1 이상), macOS 14 이상이 필요합니다.

해 보셨나요? 디스코드 한국어 채널나 호환성 보고로 알려 주시면 이 페이지에 반영합니다.
