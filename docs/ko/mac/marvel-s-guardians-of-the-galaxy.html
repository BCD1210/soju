Marvel's Guardians of the Galaxy 맥에서 하기

맥에서 됨 (Highball 실측)

Highball 관리자가 애플 실리콘 맥 M5 2026-09-09에서 자체 Wine 엔진 d3dmetal으로 직접 실행했습니다. 소주에서는 아직 실행하지 않았고 엔진이 달라 결과가 다를 수 있습니다. 메모(영문): Playable on the r5 engine, which carries the fix. DirectX 12 only: on DXMT it stops at "No suitable D3D12 adapter found" before the splash, so D3DMetal is the only mode that reaches the game, and Highball asks for Apple's licence at the first launch. Reached gameplay twice from a clean start on 2026-09-09: 27.5 fps at 1280x720 in the opening scene, 17-32 fps in play, and about 10 fps for the first minute while…

리눅스(Proton) 참고: 최근 2년 사용자 보고 33건 중 30건이 실행된다고 했습니다 (ProtonDB, 2026-11-02 기준, ODbL).

맥 자료: Highball database (CC0).

소주로 해 보는 방법

brew install BCD1210/soju/soju
soju install          # Steam 선택 (macOS 26 이상)
soju steam         # 로그인 → 게임 설치 → 플레이

또는 소주 앱을 받아 플랫폼에서 Steam을(를) 설치하세요. 애플 실리콘(M1 이상), macOS 14 이상이 필요합니다.

해 보셨나요? 디스코드나 호환성 보고로 알려 주시면 이 페이지에 반영합니다.
