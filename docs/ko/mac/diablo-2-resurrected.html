소주로 해 보는 방법

brew install BCD1210/soju/soju
soju install          # Battle.net 선택
soju battlenet     # 로그인 → 게임 설치 → 플레이

또는 소주 앱을 받아 플랫폼에서 Battle.net을(를) 설치하세요. 애플 실리콘(M1 이상), macOS 14 이상이 필요합니다.
