Soju by Didim Labs 게임 한국어 홈 GitHub 디스코드

소주는 애플 실리콘 맥에 공식 윈도우 게임 런처를 설치하는 무료 오픈소스 앱입니다.

Valheim 맥에서 하기

추정: 될 가능성 높음

맥에서는 아직 실행해 보지 않은 추정입니다. 리눅스(Proton)에서 최근 2년 사용자 보고 162건 중 155건이 실행된다고 했습니다(ProtonDB, 2026-11-02 기준). 소주는 윈도우 스팀 게임을 맥의 Wine으로 돌리고, Direct3D 11은 DXMT로 처리합니다. Direct3D 12 게임은 소주 스팀 환경에서 아직 확인하지 않았고, 안티치트나 맥 고유 문제로 리눅스와 결과가 다를 수 있습니다. 스팀 페이지에 macOS 버전이 있으면 그걸 쓰세요.

스팀 상점 페이지

런처Steam
상태추정: 될 가능성 높음
날짜2026-11-11 갱신

소주로 해 보는 방법

brew install BCD1210/soju/soju
soju install          # Steam 선택 (macOS 26 이상)
soju steam         # 로그인 → 게임 설치 → 플레이

또는 소주 앱을 받아 플랫폼에서 Steam을(를) 설치하세요. 애플 실리콘(M1 이상), macOS 14 이상이 필요합니다.

해 보셨나요? 디스코드 한국어 채널나 호환성 보고로 알려 주시면 이 페이지에 반영합니다.
