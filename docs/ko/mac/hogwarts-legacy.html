소주는 애플 실리콘 맥에 공식 윈도우 게임 런처를 설치하는 무료 오픈소스 앱입니다.

호그와트 레거시 맥에서 하기

소주에서 됨

소주의 에픽 게임즈 런처에서 설치(71GB)해 게임 안까지 플레이했습니다. 언리얼 엔진 4, Direct3D 12를 애플 D3DMetal로 돌립니다. 시작할 때 나오는 "AMD 드라이버" 경고는 무시해도 됩니다. 창 모드로 하려면 게임 안 화면 설정에서 바꾸세요.

리눅스(Proton) 참고: 최근 2년 사용자 보고 324건 중 287건이 실행된다고 했습니다 (ProtonDB, 2026-11-02 기준, ODbL).

스팀 상점 페이지

런처Epic Games Launcher
상태소주에서 됨
날짜2026-08-30, M4 Pro · macOS 26.5에서 실행

소주로 해 보는 방법

brew install BCD1210/soju/soju
soju install          # Epic Games Launcher 선택
soju epic          # 로그인 → 게임 설치 → 플레이

또는 소주 앱을 받아 플랫폼에서 Epic Games Launcher을(를) 설치하세요. 애플 실리콘(M1 이상), macOS 14 이상이 필요합니다.

해 보셨나요? 디스코드나 호환성 보고로 알려 주시면 이 페이지에 반영합니다.
