소주는 애플 실리콘 맥에 공식 윈도우 게임 런처를 설치하는 무료 오픈소스 앱입니다.

VRChat 맥에서 하기

안 됨: 안티치트

Highball 데이터베이스에서 안티치트 등으로 막힌 게임으로 분류합니다. 소주에서는 아직 실행하지 않았고 엔진이 달라 결과가 다를 수 있습니다. 메모(영문): Anti-cheat: Easy Anti-Cheat. On Windows it loads a kernel driver, which Wine cannot run, and the Linux route (EAC's own Proton runtime) does not exist for macOS, so the launch stops at 'Failed to load the anti-cheat module' on every engine and graphics mode. Linux/Proton status 'Supported' does not apply to macOS.

리눅스(Proton) 참고: 최근 2년 사용자 보고 199건 중 167건이 실행된다고 했습니다 (ProtonDB, 2026-11-02 기준, ODbL).

맥 자료: Highball database (CC0).
