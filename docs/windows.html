Don't Sell the Cat on Windows

You bought the game from us and want to play on a PC. It takes about a minute.

Install

  1. Download

    Open the Polar receipt email (or the page you saw after paying) and download DontSellTheCat-windows-1.0.zip, about 375 MB.

  2. Extract

    Right-click the zip, choose Extract All, and put the folder wherever you like.

  3. Run

    Open the folder and double-click DontSellTheCat.exe.

  4. If Windows warns you

    A blue "Windows protected your PC" window can appear the first time, because the game isn't from the Microsoft Store and we don't pay for a code-signing certificate. Click More info, then Run anyway.

Needed
Windows10 or 11, 64-bit
GraphicsDirectX 12 GPU. On older laptops set Graphics to Low in Settings.
Saves%APPDATA%\Godot\app_userdata\Don't Sell the Cat. Copy this folder to move progress to another PC.

Updates

New versions are added to your purchase. Download the zip again from the receipt link or the Polar customer portal and replace the old folder; your saves stay where they are.

On a Mac, use Soju instead: open the Didim Labs Store tab and paste your license key.
